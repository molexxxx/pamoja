# pamoja for .NET

The .NET binding for pamoja: every capability of the Rust core, one package and
namespace each, behind a C# facade over the native C ABI. This is the generated
reference for every `Pamoja` package; the guides, with a worked C# example for
each capability, are at [pamoja.molex.cloud/docs](https://pamoja.molex.cloud/docs/).
