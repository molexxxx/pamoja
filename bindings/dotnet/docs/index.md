# pamoja for .NET

**C# binding reference.** Every capability of the Rust core, one package and namespace
each, behind a C# facade over the native C ABI. The XML documentation ships in each
package too, so an editor shows the same text inline.

- [Browse the API](api/Pamoja.yml), namespace by namespace
- [The guides](https://pamoja.molex.cloud/docs/), with a worked C# example for each capability
- [The packages on NuGet](https://www.nuget.org/profiles/tonywied17)
- [Source on GitHub](https://github.com/molexxxx/pamoja/tree/main/bindings/dotnet)
