# C# reference

The [`Pamoja.Core` reference](dotnet/index.html) is generated by DocFX from the
C# facade and its XML documentation, which also ships in the NuGet package so an
editor shows the same text inline.

The facade is hand-written C# over `NativeMethods`, the P/Invoke declarations
that mirror the generated C header `pamoja.h` one-to-one; that class is the
low-level escape hatch for anything the facade does not cover.
