# TypeScript reference

The [`@pamoja/core` reference](node/index.html) is generated by typedoc from the
TypeScript facade. Each capability is a subpath of the package, so an import
names the capability it uses, and the module page for each one lists its
classes, functions, and types.

The facade is hand-written TypeScript over the generated napi-rs contract in
`index.d.ts`; `@pamoja/core/raw` exposes that contract directly for anything the
facade does not cover.
