# TypeScript reference

The [TypeScript reference](node/index.html) is generated by typedoc from every
`@pamoja` package. Each capability is its own package, so an import names the
capability it uses, and the page for each package lists its classes, functions,
and types. `pamoja` bundles all of them.

Each package is hand-written TypeScript over `@pamoja/native`, the compiled
engine and its generated napi-rs contract, which stays importable for anything
the facades do not cover. `@pamoja/core` is the engine's own surface, the
counterpart of the `pamoja-core` crate.
